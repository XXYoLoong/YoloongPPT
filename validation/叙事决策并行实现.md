# 叙事决策并行实现

## 原始需求关联

已读取两份 V0.3 原文件中的 DEC-006–021、CNT-005–014、SYS-005，以及原 Excel 的 TASK-DEC-006–021、VERIFY-DEC-006–021 和 S11–S17。RES-031 是这些节点的原始研究依赖，未新增全量研究前置。

## 可执行结果

- `narrative.prepare` 在真实模型调用前执行受众、场景、语言/语气、词法关系候选、故事线候选和绑定页数预算；`model_packet` 直接给现有模型消费。
- `narrative.finalize` 处理实际模型规划，保存可追溯主旨与支持点、页级章节对象、章节预算、分页、页目标、页面类型、标题层级、内容容量、完整段移入备注的 before/after、notes 来源位置和源身份回链。
- `run_node` 与主链使用同一实现，支持 DEC-006–021 的独立执行与输入/候选/排序/规则/输出轨迹，P01–P05 对应路径随轨迹记录。候选评分是确定性政策排序；置信度未知，不冒充统计置信度。
- 不截断文字、丢弃表格行列或补空页；正文中的假设、推算、已选来源与占位标签保持可见。标记或核心段过载明确阻断。

docker --context desktop-linux compose exec -T app python /workspace/validation/verify-narrative-runtime.py
