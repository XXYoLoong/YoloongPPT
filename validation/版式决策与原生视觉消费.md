# 版式决策与原生视觉消费

## 对应需求与实际实现

原始需求行：DEC-030–038、SYS-010/011、TPL-007/011/012/013。原始验收要求包括独立节点、至少三个常规和一个边界样例以及 P01–P05 对应研究；本轮保持这些编号，不将当前原生子集等同于完整验收。

- `layout_decisions.run_stage(node_id, payload, registry=None, schemas=None)` 独立运行九个节点，消费与输出 schema、原始输入、机制、约束、fallback、来源 hash 和 P01–P05 固定研究映射路径均进入 trace。未发现稳定节点编号的研究映射保留 unknown，不伪造全对应。
- `layouts.choose` 保持原三元返回值及旧 title/body/footer/data、body.N 槽位，串联候选、选择、绑定、几何、字体、颜色、图片、备注及后端预检查。文字容量失败可以尝试已声明其他候选；全部失败时停止，不改写/截断/缩小原文。
- 图片来自已解析资产，contain 保持比例与全部像素；caller 明确指定的 cover/crop 使用实际尺寸、焦点和四边比例。低 DPI 在 trace 提醒，不伪造放大质量。模型协议本轮仍只允许 contain，cover/crop 为独立节点的显式政策入口。
- 来源明确图示展开为原生形状与连接线，保留 node_id、label、edge relation、引用和方向端点。流程、时间线、树/网络/矩阵/漏斗仅消费显式节点拓扑，槽位范围 2–12 节点；树须单根无环单亲。泳道缺少显式分组时拒绝，不猜分组。连接线标签本轮写入原生描述而非额外可见标签；高级路由与完整图示语义验收仍未完成。
- 采用实测 Noto 字形和最小字号，未安装字体与 RTL 明确失败；固色文字按计算对比度阻断，未经实现的渐变/阴影/透明请求不忽略。默认无动画/切换，备注原样保留。
- PP-05 预检查用实际 AtomicRegistry 选择精确平台/版本；必要能力缺口、未知后端要求、Office round-trip/live/pixel-exact 请求失败，不替换其他后端。无 registry 的独立几何调用保留 untested，不报告通过后端验收。

## 验证与证据

执行 `docker --context desktop-linux compose exec -T app python /workspace/validation/verify-layout-stages.py`，报告 `validation/layout-stage-artifacts/layout-stages.json` 与完整节点输出 `layout-traces.json`。每节点三个常规及一个边界/冲突，另含图片适配、原生图示槽位、RTL、文本超容量、裁切政策、未知对象等直接检查。本模块不调用模型，不替代真实生成、渲染与完整系统 AC。

第一次新能力检查发现共享 atomic catalog 先于 schema 更新，报 `/version`、`/capabilities` 和新增名称校验错误；由主智能体同步共享 schema 后，实际 registry 的图片/图示候选通过。独立几何证据未被当成后端运行证据。

完整品牌锁、自定义模板选中消费、页面比例、复杂图示自动路由、全部图片蒙版/效果、字体 fallback/RTL、Office/live、多后端和原始节点/系统 AC 验收仍未完成；相关原需求应保持进行中。

## 四页原生执行与真实渲染组件集成

`verify-visual-execution.py` 复用上一视觉直接验证保存的批准字面样例、真实 PNG 和宽屏模板。无模型调用，未把人工组件样例宣称 AI 生成或系统验收。prepare/finalize 后生成图片页、原生流程页、表格页和图表页，经 compiler/atomic/writer、实际 LibreOffice PDF/四张 PNG、确定性 QA、DEC-039/040。

23 项组件检查通过，P0 为 0；低分辨率来源图片被真实测为约 38.65 DPI 并保留 `IMAGE_RESOLUTION_LOW` P1。DEC-040 返回 warning、final_allowed=false，语义复审和 AC-001/GOV-008 仍未通过。图片嵌入 bytes/hash、原生节点文字、两条连接线、表格/图表值及内嵌工作簿均核对。调用者模板增加独特主题标记以区别默认模板，25 个 master/layout/theme 部件 payload 字节完全保持；不存在可用空白版式的模板明确在写入前失败。

实际执行首次发现 add_shape/add_connector 原子输入契约遗漏 format 字段，未写 PPTX；对应失败输入已保存。主智能体补齐共享契约后再次执行，才得到上述真实产物。证据为 `validation/visual-execution-artifacts/`，其 manifest 列出白名单导出文件和原始字节 hash。没有复制数据库、密钥或整个 runtime。
