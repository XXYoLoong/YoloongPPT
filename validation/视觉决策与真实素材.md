# 视觉决策与真实素材

## 原需求与当前交付

依据原 DOCX 和 XLSX 的 DEC-022–029、TASK/VERIFY-DEC-022–029、SYS-008/009、TPL-001–006、AST-001–007/010–012/014/016 原始行实现。保留全部原验收；本模块样例通过不等于原需求全完成，也不等于 AC 通过。

- `visual.prepare` 在实际文案模型调用前解析模板族/风格和调用者显式提供的素材，给出可消费的资产 ID、规格与许可状态。
- `visual.finalize` 在规划之后执行视觉表达、图片角色/数量、实际素材选择、表格维度、图表类型及关系图引用检查，并返回供原生对象编译器消费的字段。
- `visual.run_node` 使用同一实现独立运行 DEC-022–029，返回输入、候选、选择、约束、fallback、P01–P05 映射和 trace。
- `asset_resolver.resolve` 实际读取并校验图片原始字节、hash、编码、MIME、像素、多帧、调用者授权与最低像素门槛。缓存以内容 hash 寻址，临时写入后原子替换；缺失/错误/未授权素材不会变成空白或虚构图片。
- HTTP 下载需要调用者开启，只允许 HTTPS 443、公共 DNS 地址、固定解析地址与原主机 TLS 校验；不自动跟随 redirect。在线公开资源下载本轮没有执行，不报为已验收。
- `template_registry` 持久登记实际 PPTX、原母版/布局/主题/槽位、来源、license、版本/hash、结构预览，支持查询与真实文件hash复核。调用者选定模板尺寸不符时拒绝，未悄悄换默认模板。

## 接口

```python
packet = visual.prepare(task, approved_sources, presentation_context, schemas, artifacts)
effective_proposal, result = visual.finalize(proposal, packet, approved_sources, schemas, artifacts)
visual.run_node('DEC-027', {'task': task, 'sources': approved_sources,
    'context': presentation_context, 'proposal': proposal}, schemas)
```

模型图片字段 `asset_id/role/alt_text/fit/required` 由实际素材登记供选择，运行时补 `path/width_px/height_px/sha256/source_refs`。图片默认 `contain`，不偷偷裁切。原模型声明保留在 DEC-024 的 `model_image_declaration`。

关系图为 `type/nodes/edges/direction`，节点为 `node_id/label/evidence_refs`，边为 `from/to/relation/evidence_quote/evidence_refs`。流程/时间线顺序必须来自批准原文的明示箭头及方向，节点标签是引用原文。普通“然后/因为/导致”词法提示不构成已证关系或因果。图的文字与连线由后续原生 shape/connector 执行，不只输出一张不可编辑图片。

### 路径安全补充（SEC-001）

另行执行 `verify-visual-path-guards.py`，23 项直接检查通过：素材和模板消费者、实际敏感路径、指向敏感文件的真实链接、真实链接越界、路径遍历、普通合法路径/根内普通链接，以及原 8 个 schema hash 保持不变。使用的均为测试文件，不读取系统真实凭据；拒绝样例对文件字节读取进行了断言。

`validation/visual-path-guards.json` 保存本次当前源码 hash、完整原 8 个 schema hash 及此前 50 项的原始来源 hash。此前 50 项报告保持原有证据，不改为新源码已全量重跑；本次只验证新增路径安全行为。第一次验证遇到 F 盘大小写不敏感导致 `secrets/SeCrEtS` 夹具目录已存在，改为兼容夹具建目录后通过；不曾读取凭据，不是产品拒绝策略失效。
