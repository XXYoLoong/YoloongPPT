# 输入格式与原生模板实装

## 原需求与实际接口

直接读取原 DOCX 与 Excel 对应 IN-003/004/006/007/008/010/011/012/015/016、TPL-001/002/003/004/005/009/014、AST-001/004/011、SEC-004/005/006 行；原 ID 和完整验收不变。

- `input_formats.parse_input(kind, raw, source_id=..., asset_id=..., locator=...)` 输出原生结构、canonical SourceAnchor、证据段、解析版本、原始 SHA256 和显式 warnings。原始字节由 EvidenceStore 保存。SourceLoader 接入由主智能体统一完成。
- DOCX 保留标题/题注/段落、表格单元格、图片关系、超链接、header/footer/footnotes/endnotes、原 XML 与全部包部件哈希；物理页码标为 pending，不用段落号伪装页码。
- XLSX 保留 20-sheet 原基线实物的 sheet/cell/type/table/merge/style/formula/cache、日期格式候选、drawing relationships 和原 XML；不执行公式，不假定缓存值新鲜或把数值伪称为 Excel 显示字符串。CSV 保留多行引号字段、不等长行及 record/field 原生锚点。
- PPTX 内容源保留 slides/shape/text/table/chart/image/notes/geometry/relationships、图表原 XML、母版、布局、主题。完整 XML/原包快照保留群组与未解释对象；未声称完整 Office 行为或编辑重建。
- PDF 使用现有 Poppler 实际执行 `pdfinfo`、`pdftotext -bbox-layout`、`pdfimages -list`，保留页号、文本块、行字、坐标、图像清单。无文本页明确要求 OCR，未静默当作空白。
- JSON 保留树、数组和类型，拒绝重复键和 NaN/Infinity；XML 保留原文与根结构并拒绝 DTD/实体；YAML 显式 unsupported。
- 图像保留像素、格式、alpha、DPI、aspect、ICC 哈希、frame count，实际计算主色与 dHash。证据文本为空，不把元数据当作图中文字或事实。资产目录保留文件哈希、类型、unknown 许可、local 来源、完全重复组和感知哈希候选，未经语义确认不宣称语义重复。
- `templates.parse_template` 实际解析 master/layout/theme/placeholder/geometry/inheritance/color/font/native XML；`query_layouts` 给出结构候选与明确理由；`instantiate_template` 真实新增原生文本占位符页并核对母版/布局/主题结构保持。

## 已执行的 Docker 验证

在确认 `F:/DockerDesktopWSL/disk/docker_data.vhdx` 与 Docker 设置一致后，执行：

```text
docker --context desktop-linux compose exec -T app python /workspace/validation/verify-input-formats.py
```

最终 31 项通过，完整结果位于 `validation/input-format-artifacts/input-formats-runtime.json`。包括实际读取两份原始基线、正常/边界输入、formula 缓存缺失、真实 PPTX 表格/图表/图片/备注、原生模板新增页面、实际 PDF 文本坐标，以及格式伪装、损坏、OLE加密/旧格式、ZIP路径逃逸、CSV引号、JSON重复键/非有限数、XML实体拒绝。所有生成与临时文件位于 `/runtime` 对应 F:。

第一次验证脚本错误假设模板只有一个 theme；包含 notes master 的真实 PPTX 有两个 theme，已修正断言为保留全部 themes。第二次执行被 app 重启中断，没有形成完成证据；协调验证窗口后第三次通过。没有调用模型或重复全链路生成。

显式导出七个白名单实物及 manifest：合成 DOCX、XLSX、原生 PPTX、PNG、PDF、实际实例化的双页 PPTX、报告；没有复制密钥、SQLite 或整个 runtime。
