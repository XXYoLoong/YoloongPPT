# 执行质量检查与局部修订决策

## 原需求与交付

读取原 Word 的 S34–S40、DEC-039/040、SYS-015/016、质量章节及原 Excel 的 DEC-039/040、QA-001–020、REV-001–010 实际行后实施。本工作包对应 DEC-039/040、SYS-015/016、QA-001/003/004/005/006/008/009/010/011/012/014/015/016/018/019/020、REV-006/010；保留全部原范围，不把本组件实物等同系统 AC。

- `quality_rules.py` 实际解析 PPTX 的 Content_Types、内部关系目标/ID，检查空对象、实际与规格几何、非设计性碰撞、字号、标题层级、规格与实际段落/run 颜色对比、图片像素密度/拉伸/替代文字、原生图示文字及连接线说明、图表和表格头、可编辑对象及字体/页脚等全局一致性。背景/装饰和真正的连接线不误判为正文碰撞，合法水平/竖直连接线允许一维零长度，未放宽其他对象。
- `quality.py` 保持原接口，原事实/假设/备注/已否决值审计继续运行；新增图像替代文字、节点和连接线的可见/原生文字也检查选定数值边界，未知数字不能通过新增对象类型逃避 QA。图表类别、系列名、单位继续对照实际原生图表。
- 每条 issue 明确 slide/object、Requirement ID、严重度、measurement/evidence、threshold、action。不把数值成员关系、OOXML XML 能解析或一次模型审查当语义真值。
- `revision_plans.py` 生成对象/页范围、before spec、预期原生映射、issue 归属、候选、局部 rerun 节点和 revision history 输入。当前自动准备 geometry 与文字颜色 format；内容、事实、语义、替代文字和不确定碰撞需明确输入或 fail；锁定对象/页的 P0 不允许跳过。执行前复核 before spec、映射及锁，历史的 byte 保留由执行器填实际证据。
- `quality_decisions.py` 运行 DEC-039/040 独立输入/候选/证据/score/reason/output/error/retry 轨迹，映射 P01–P05 原实现线索。P0 必须 fail；DEC-001–038 的已有轨迹以及当前 DEC-039/040 必须完整，空策略列表不能删除基线；缺少完整 coverage/节点/AC 即 warning 或调用者规定的 fail。`final` 只用于所有明确要求已证明且没有 issue；不把实际 8 页 P0=0 升为完整 final/AC 通过；system_acceptance=passed 额外要求 AC-001–030 全部已通过。重试数有明确上限。

## 接口与实际消费

`quality.check(deck,pptx,object_map,sources,renders,root)` 保持原签名。

`quality_decisions.decide(document,schemas=None,trace=None)` 输入 `quality_report/deck/object_map/revision_policy?/completion_policy?/prior_traces?/parent_run_id?`，输出 `revision_plan/completion/decision_traces`。`run_node(document,node_id,schemas=None,trace=None)` 单独运行 DEC-039/040。

`revision_plans.validate_plan(plan,deck,object_map)` 在执行前拒绝阻断、过时映射/规格、非法边界和未知操作。`history_input(...)` 给实际执行器保存 before/after hash、对象变化及 QA，不伪造 byte-preserved。主智能体在 `revision.py` 统一接入实际 geometry/format 执行；本子模块不编辑共享入口和主链路。
