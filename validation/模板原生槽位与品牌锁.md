# 模板原生槽位与品牌锁

关联原始需求：AC-006、TPL-002/003/004/006/008/015/016及对应 TASK。完整验收仍为进行中；三上游模板、全部页面模式、PowerPoint 桌面和所有 AC 尚未完成。

## 本次实现

- `template_layout_runtime.choose` 从指定 PPTX 的真实 layout/placeholders 选择、映射和测量内容，返回实际布局、原生槽位索引、实际字体文件、保守容量测量及选择/拒绝原因。
- `create_slide` 创建指定原生 layout 的页面；`bind_placeholder` 查找现有 placeholder 并复核布局、类型和几何。文本、图片、表格及图表填写使用现有原生 placeholder；不在指定模板上覆盖浮动对象。
- 同一模板文件的来源、许可证或策略变化产生新的登记 ID。已登记策略、来源和许可证不能被调用 metadata 静默改写；旧登记 ID 保留查询兼容。
- 品牌策略显式声明母版/布局中的锁定对象、英寸安全区域/内容区和颜色/字体 token。锁定对象不成为可写内容槽位；相交、token 冲突和字段不匹配明确失败。
- fallback 仅使用已持久化的调用者 `fallback_layouts`，记录首选布局拒绝原因及实际差异。无合适槽位、容量不足、缺字体、图示/图库尚无对应原生槽位时停止。
- `preserve_package` 保存原母版、布局、主题、媒体及未知 OOXML 部件的原始字节；未知关系 ID 冲突时拒绝，保留语义未知状态。

## 策略接口

`register(..., policy=...)` 接受内联 `template-policy-1` JSON：`layout_part`、`layout_by_kind`、`field_map`（统一角色到实际 idx/name）、`fallback_layouts`、`typography` 及 `brand`。策略 schema 拒绝未知字段。路径输入的 `sources[].metadata.template_policy` 在登记时保存；已登记 ID 的 metadata 只能与原策略完全相同。

图像 `contain` 保持像素纵横比，以原生图片槽位内的 fit box 填充，记录 `original_slot_bounds`，没有默认裁剪。`cover/crop` 需要已有显式裁剪记录。表格/图表只接受真正具有插入接口的 `tbl/chart` placeholder，普通 `obj` 不冒充复杂对象槽位。

## 两个增量模板输入边界

- `kind=image` 仅带多图 `images` 时明确返回 `TEMPLATE_GALLERY_SLOTS_UNSUPPORTED`，不再取不存在的 `image` 触发 KeyError，也不取第一张图或切换通用模板。目前模板多原生图槽尚不支持。
- 单图 `cover` 只有 focal point 而没有已解析 crop 时继续明确拒绝，候选原因是 `TEMPLATE_IMAGE_FIT_UNSUPPORTED`。没有把这项尚未执行的能力改成可用；显式错误为 `TEMPLATE_NO_COMPATIBLE_LAYOUT`，保留候选拒绝原因。

## 保留的失败与修复证据

1. `failed-001.json`：缺少 `obj→master body` 原生继承映射，第一普通案例未能选择正文槽。Docker 中实际 python-pptx `LayoutPlaceholder._base_placeholder` 源码确认后，解析器采用对应 master 类型映射。
2. `failed-002.json`：LibreOffice 没有输出 PDF。`package-diagnostic.json` 表明删除未知部件仍失败；`namespace-diagnostic.json` 单变量对照只将 ContentTypes 改为默认命名空间，保留所有未知部件，立即生成 PDF。修复使用局部 lxml namespace 序列化，避免 ElementTree 的前缀兼容问题和全局 namespace 竞争。
3. `failed-003-driver-startup.json`：追加验证 checkpoint 时漏掉一行缩进，产品函数尚未执行；恢复驱动缩进后当前完整限定验证成功。实际失败数 3 次，对应 L2，没有隐去这次脚本失败。

以上是组件及正式编译/写入器集成证据，**不等于 AC-006 完整通过**。三上游模板族、所有页面模式、复杂品牌样式、全部 OOXML 语义和 PowerPoint 桌面验收仍未完成；LibreOffice 能渲染也不证明 PowerPoint 全兼容。
