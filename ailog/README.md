# 项目变更日志

每项项目变更新建两份 UTF-8 Markdown 日志，分别保存在 ailog/ 和 development-log/，不覆盖历史记录。

- 文件名：中文简要概括任务内容_YYYYMMDD-HHmmss.md，标题像简洁的对话标题；不得使用英文 slug。
- 两份日志使用相同的中文标题和时间戳。
- 时间：使用本地时间，精确到秒。
- 内容：简述需求、修改文件、执行命令、验证结果和 Git 提交/推送状态。
- 两份日志与对应的项目改动一起提交到 yoloongdevlop 并推送到 origin/yoloongdevlop。
- 禁止记录密钥、令牌、密码和 .env 文件内容。
